★ Standalone offline file — no internet needed

Offline mode uses fonts already installed on your device — no font files are downloaded. If a script shows as boxes (tofu), please install a font for that script on your OS (e.g. Pyidaungsu / Myanmar Text for Myanmar, Noto Sans Sinhala for Sinhala).

How to use

  1. Choose the target script from the dropdown above — your choice is remembered.
  2. Type using Velthuis (e.g. aa → ā, .m → ṃ) — or paste text in any of the 17 scripts.
  3. The output converts instantly as you type. Copy it, or grab the offline tool below.
