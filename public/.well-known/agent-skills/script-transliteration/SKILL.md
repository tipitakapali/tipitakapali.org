# Pāḷi Multi-Script Transliteration Skill

TipitakaPali.org supports 100% loss-free, reversible phonological transliteration between Roman script and 16 Asian Brahmic scripts.

## Supported Script Prefixes
- `si`: Sinhala (සිංහල)
- `hi`: Devanagari / Hindi (देवनागरी)
- `my`: Myanmar / Burmese (မြန်မာ)
- `thai`: Thai (ไทย)
- `laos`: Lao (ລາວ)
- `km`: Khmer (ខ្មែរ)
- `beng`: Bengali (বাংলা)
- `gurm`: Gurmukhi (ਗੁਰਮੁਖੀ)
- `tham`: Tai Tham / Lanna (ᨲ᩠ᩅᩫᨾᩮᩥᩬᨦ)
- `guja`: Gujarati (ગુજરાતી)
- `telu`: Telugu (తెలుగు)
- `kann`: Kannada (ಕನ್ನಡ)
- `mala`: Malayalam (മലയാളം)
- `brah`: Brahmi (𑀩𑁆𑀭𑀸𑀳𑁆𑀫𑀻)
- `tibt`: Tibetan (བོད་སྐད།)
- `cyrl`: Cyrillic (кириллица)
